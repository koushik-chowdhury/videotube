# Video Listing App (YouTube Style)


## What I Built

- A video listing interface that fetches data from an external API
- Reusable components for video cards and layout
- A responsive grid layout similar to YouTube
- Clean project structure using API layer, hooks, and components
- Basic loading system

---

## Features

- Fetch videos from a public API
- Display video thumbnails, titles, channel names, and views
- Responsive grid layout for video cards
- Reusable components (VideoCard, VideoGrid)
- Custom hook for data fetching
- Loading state while fetching data
- Error handling for failed API requests
- Clean UI using custom CSS

---

## Tech Stack

- React
- Vite
- Axios
- JavaScript (ES6+)
- CSS (custom styling)

---

## API Used
- https://api.freeapi.app/api/v1/public/youtube/videos
